# Datos de ejemplo

Datos **inventados** para desarrollo y demo. `planner --ejemplo` copia esta carpeta a un directorio temporal y trabaja sobre la copia: esta carpeta nunca se modifica.

El escenario reproduce la maqueta: la semana 45 (2 – 8 nov 2026) en curso, la 44 sin cerrar y las anteriores cerradas. Para verlo como en la maqueta: `planner --ejemplo --hoy 2026-11-02`.
